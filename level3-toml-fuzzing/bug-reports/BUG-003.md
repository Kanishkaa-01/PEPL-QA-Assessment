# BUG-003: TOML Parser Accepts an Incomplete Array

**Severity:** High  
**Component:** TOML Decoder  
**Discovered using:** Hypothesis differential fuzzing

## Description
The `toml` library accepts an incomplete TOML array that Python's built-in `tomllib` parser correctly rejects.

## Steps to Reproduce
1. Provide the TOML document `name = [1, 2,`.
2. Parse it using `toml.loads()`.
3. Parse the same document using `tomllib.loads()`.
4. Compare the acceptance or rejection results.

## Input
```toml
name = [1, 2,
```

## Expected Result
Both parsers should reject the incomplete array with a parsing error.

## Actual Result
- `toml==0.10.2` accepts the document.
- Python `tomllib` raises `TOMLDecodeError`.

## Impact
Malformed TOML documents may be accepted as valid, potentially causing inconsistent parsing between applications.
