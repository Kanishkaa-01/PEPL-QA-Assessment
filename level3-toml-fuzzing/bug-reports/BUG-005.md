# BUG-005: Parser Accepts an Incomplete Array

**Severity:** High

**Component:** TOML Decoder

**Library:** toml 0.10.2

## Description
The parser accepts an incomplete TOML array without a closing
square bracket and interprets it as an empty array.

## Steps to Reproduce
1. Import toml and tomllib.
2. Pass `array = [` to both parsers.
3. Compare their results.

## Expected Result
Both parsers should reject the invalid TOML document.

## Actual Result
- toml 0.10.2 accepts the document and returns `{'array': []}`.
- Python tomllib raises TOMLDecodeError.

## Evidence
See `minimized-cases/bug-005-parser-accepts-incomplete-array.py`.

## Why It Matters
Accepting malformed configuration files can cause invalid
configuration data to be silently interpreted as valid data.
