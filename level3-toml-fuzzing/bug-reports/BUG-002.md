# BUG-002: TOML Encoder Crashes on Control Character in Key

**Severity:** High  
**Component:** TOML Encoder  
**Discovered using:** Hypothesis property-based testing

## Description
The TOML encoder raises an unexpected `IndexError` when a dictionary key contains the control character `\x1f`.

## Steps to Reproduce
1. Create a Python dictionary with the key `'\x1f'`.
2. Pass the dictionary to `toml.dumps()`.
3. Observe the exception.

## Input
```python
data = {'\x1f': 0}
```

## Expected Result
The encoder should either serialize the key correctly or raise a clear, documented validation error.

## Actual Result
The encoder raises:

```text
IndexError: list index out of range
```

## Impact
The serialization process crashes unexpectedly for this input.
