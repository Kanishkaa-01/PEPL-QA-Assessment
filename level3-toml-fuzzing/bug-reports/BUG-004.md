# BUG-004: TOML Parser Accepts an Incomplete Inline Table

**Severity:** High  
**Component:** TOML Decoder  
**Discovered using:** Hypothesis differential fuzzing

## Description
The `toml` library accepts an incomplete inline table that Python's built-in `tomllib` parser rejects.

## Steps to Reproduce
1. Provide the TOML document `key = {`.
2. Parse it using `toml.loads()`.
3. Parse the same document using `tomllib.loads()`.
4. Compare the results.

## Input
```toml
key = {
```

## Expected Result
Both parsers should reject the incomplete inline table.

## Actual Result
- `toml==0.10.2` accepts the document.
- Python `tomllib` raises `TOMLDecodeError`.

## Impact
Malformed TOML may be accepted as valid, potentially resulting in inconsistent interpretation between applications.
