# BUG-001: TOML Encoder Corrupts Control Characters in Keys

**Severity:** High  
**Component:** TOML Encoder  
**Discovered using:** Hypothesis property-based testing

## Description
The TOML encoder does not correctly preserve certain control characters in dictionary keys during serialization.

## Steps to Reproduce
1. Create a Python dictionary with the key `'0\x1f'`.
2. Serialize it using `toml.dumps()`.
3. Parse the serialized output using `toml.loads()`.
4. Compare the parsed dictionary with the original dictionary.

## Input
```python
data = {'0\x1f': 0}
```

## Expected Result
The parsed dictionary should exactly match the original dictionary.

## Actual Result
The serialized output is:

```toml
"0x1f" = 0
```

The parsed result becomes:

```python
{'0x1f': 0}
```

## Impact
Data integrity is compromised because dictionary keys are silently changed during serialization.
