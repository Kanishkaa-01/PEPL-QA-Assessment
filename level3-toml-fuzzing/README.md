# Level 3 – TOML Differential Fuzzing

## 1. Project Overview

This project performs differential fuzz testing on the Python TOML library `toml==0.10.2` by comparing its behaviour with Python's built-in `tomllib` parser.

The objective is to identify serialization and parsing defects using property-based testing, minimize failing inputs, document root causes and propose fixes.

## 2. Technologies Used

- Python 3.11
- pytest
- Hypothesis
- toml 0.10.2
- tomllib (Python standard library)

## 4. Testing Approach

### Property 1: Serialization Round-Trip

Checks whether data serialized using `toml.dumps()` can be parsed using `toml.loads()` without changing the original data.

### Property 2: TOML Compatibility

Checks whether TOML generated by `toml.dumps()` can also be parsed correctly by Python's built-in `tomllib`.

### Property 3: Differential Fuzzing

Generates valid TOML documents, malformed TOML inputs and arbitrary TOML-like text.

Compares the behaviour of `toml.loads()` and `tomllib.loads()` to identify differences in acceptance, rejection and parsed results.

Hypothesis is used to generate test inputs and minimize failing examples.

## 5. Bugs Discovered

| Bug ID | Description | Component |
|---|---|---|
| BUG-001 | Control characters corrupt dictionary keys | Encoder |
| BUG-002 | Encoder crashes on control characters | Encoder |
| BUG-003 | Incomplete array is accepted | Decoder |
| BUG-004 | Incomplete inline table is accepted | Decoder |
| BUG-005 | Incomplete array is interpreted as empty | Decoder |

Detailed reports and minimized reproduction scripts are available in the `bug-reports/` and `minimized-cases/` folders.

## 6. Root Cause Analysis

The encoder defects are related to incorrect handling of control characters in the `_dump_str()` function.

The decoder defects are related to insufficient validation of closing delimiters in `load_array()` and `load_inline_object()`.

Python's built-in `tomllib` was used as the reference parser for differential comparisons.

See `results/root-cause-analysis.md` for the detailed analysis.

## 7. Proposed Fixes

Two isolated proposed fixes were implemented:

- **Encoder fix:** Added string escaping logic to preserve control characters.
- **Decoder fix:** Added validation to reject arrays without matching opening and closing brackets.

Both proposed fixes were tested independently. They do not modify the installed `toml` package.

## 9. Running Tests

Run the complete test suite:

```powershell
pytest -v
```

Run individual property tests:

```powershell
pytest tests/test_roundtrip.py -v
pytest tests/test_tomllib_compatibility.py -v
pytest tests/test_differential.py -v
```

Run proposed-fix tests:

```powershell
pytest tests/test_fixed_encoder.py tests/test_fixed_decoder.py -v
```

Run known-bug regression tests:

```powershell
pytest tests/test_known_bugs.py -v
```

## 10. Test Results

Latest complete test execution:

- 9 tests passed.
- 5 tests marked as expected failures (XFAIL).
- 0 unexpected failures.

The expected failures correspond to the five documented defects in the original `toml==0.10.2` library.

The proposed encoder and decoder fixes passed all six independent regression tests.

## 11. Conclusion

Differential fuzzing identified five defects in `toml==0.10.2`, including encoder data corruption, an encoder exception and acceptance of malformed TOML documents.

Hypothesis helped discover and minimize the failing inputs. Python's built-in `tomllib` provided a reference for comparing parser behaviour.

The project also includes root-cause analysis, reproduction scripts and two independently tested proposed fixes.
