# BUG-002: Contact Form Displays an Incorrect Subject Required Error

**Severity:** High  
**Priority:** High  
**Status:** Open  
**Module:** Contact Form  
**Environment:** Chromium browser  
**Application:** Toolshop – Bug-injected build  
**URL:** https://with-bugs.practicesoftwaretesting.com/#/contact

## Preconditions
- The website is accessible.
- The user is on the Contact page.

## Steps to Reproduce
1. Open the bug-injected website and navigate to Contact.
2. Enter a valid first name, last name, and email address.
3. Select "Customer service" from the Subject dropdown.
4. Enter a message.
5. Click Send.

## Expected Result
The form should accept the selected subject and submit the message, displaying a success confirmation.

## Actual Result
The application displays "Subject is required" even though "Customer service" is visibly selected. The form does not submit successfully.

## Evidence
- `screenshots/contact-subject-required-error.png`
- Automated test: `tests/test_contact.py::test_contact_form_successful_submission`

## Impact
Users may be unable to submit contact requests despite completing the required fields.

## Reference Build Comparison
- Reference build: Contact form submission test passed.
- Bug-injected build: Submission test failed with the subject-required error.

## Reproducibility
Reproduced using the automated Playwright test.
