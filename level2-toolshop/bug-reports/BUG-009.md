# BUG-009: Product Sorting Does Not Arrange Products Correctly

**Bug ID:** BUG-009  
**Title:** Product sorting displays products in an incorrect order  
**Severity:** Medium  
**Priority:** High  
**Status:** Open  
**Module:** Product Listing / Sorting  
**Environment:** Chromium Browser  
**Application:** Toolshop – Bug-injected build  
**URL:** https://with-bugs.practicesoftwaretesting.com

## Preconditions
- The Toolshop website is accessible.
- The user is on a product listing or category page.
- Multiple products are displayed.

## Steps to Reproduce
1. Open the bug-injected Toolshop website.
2. Navigate to a product category, such as Hand Tools.
3. Select **Price (Low - High)** from the sorting dropdown.
4. Observe the order of product prices.
5. Repeat the test using the following sorting options:
   - Price (High - Low)
   - Name (A - Z)
   - Name (Z - A)

## Expected Result
Products should be arranged correctly according to the selected sorting option:

- **Price (Low - High):** Products should appear from the lowest price to the highest price.
- **Price (High - Low):** Products should appear from the highest price to the lowest price.
- **Name (A - Z):** Products should appear in alphabetical ascending order.
- **Name (Z - A):** Products should appear in alphabetical descending order.

## Actual Result
Products appear in an inconsistent and incorrect order despite selecting the sorting options. The selected sorting option does not correctly arrange the displayed products.

## Evidence
- Screenshot showing incorrect product ordering for Price (Low - High).
- Additional screenshots showing incorrect ordering for other sorting options, where available.

## Impact
Customers may find it difficult to locate products based on price or name. Incorrect sorting creates confusion and reduces the usability of the product listing page.

## Reference Build Comparison
- **Correct reference build:** Products are sorted correctly according to the selected option.
- **Bug-injected build:** Products appear in an incorrect order for the sorting options.

## Reproducibility
Observed manually on the bug-injected build across all four sorting options.
