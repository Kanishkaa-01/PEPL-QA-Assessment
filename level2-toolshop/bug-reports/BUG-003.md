# BUG-003: Incorrect Sorting Section Heading

**Severity:** Low  
**Priority:** Low  
**Status:** Open  
**Module:** Product Listing / Sorting  
**Application:** Toolshop – Bug-injected build

## Steps to Reproduce
1. Open the bug-injected website.
2. Navigate to the product listing page.
3. Locate the sorting section.
4. Read its heading.

## Expected Result
The heading should display "Sort".

## Actual Result
The heading displays "Sorth".

## Evidence
Screenshot of the bug-injected build showing "Sorth". The reference build displays "Sort".

## Impact
The spelling error reduces the professionalism and consistency of the interface.

## Reference Build Comparison
- Reference build: "Sort".
- Bug-injected build: "Sorth".

## Reproducibility
Reported as consistently visible during comparison.
