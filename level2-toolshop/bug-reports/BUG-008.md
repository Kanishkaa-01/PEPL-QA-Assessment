# BUG-008: Incorrect Category Names Displayed in Categories Dropdown

**Bug ID:** BUG-008  
**Title:** Categories dropdown displays an undefined category  
**Severity:** High  
**Priority:** High  
**Status:** Open  
**Module:** Product Categories / Navigation  
**Environment:** Chromium browser  
**Application:** Toolshop – Bug-injected build

## Preconditions
- The Toolshop website is accessible.
- The user can access the Categories dropdown.

## Steps to Reproduce
1. Open the bug-injected Toolshop website.
2. Click the Categories dropdown.
3. Observe the category names.
4. Select the UNDEFINED category.
5. Observe the page heading and URL.

## Expected Result
The dropdown should display valid, meaningful category names. Selecting a category should open the corresponding category page with the correct category name.

## Actual Result
The dropdown displays "UNDEFINED" instead of a meaningful category name. Selecting it opens a page displaying "Category: Undefined" with the URL `#/category/undefined`.

## Evidence
- Screenshot of the bug-injected Categories dropdown.
- Screenshot showing the Category: Undefined page.
- Reference-build screenshot showing Other and Special Tools instead.

## Impact
Users may be confused by invalid category names and may have difficulty finding products in the intended categories.

## Reference Build Comparison
- Reference build: Displays Hand Tools, Power Tools, Other and Special Tools.
- Bug-injected build: Displays Hand Tools, Power Tools, UNDEFINED and Chainsaws.

## Reproducibility
Observed during manual comparison of the two builds.
