# BUG-007: Product Page Action Buttons Overlap

**Severity:** Medium (provisional)  
**Priority:** Medium (provisional)  
**Status:** Open 
**Module:** Product Details / User Interface  
**Application:** Toolshop – Bug-injected build

## Steps to Reproduce
1. Open the bug-injected website.
2. Open a product details page.
3. Locate Add to Cart and Add to Favourites.
4. Observe their alignment and spacing.

## Expected Result
Both action buttons should be clearly separated, readable, and positioned without overlapping.

## Actual Result
The supplied screenshots show the Add to Cart and Add to Favourites controls overlapping.

## Evidence
Screenshots supplied during testing showing the product page controls.

## Impact
Overlapping controls may make the buttons difficult to read or select and can cause users to activate the wrong action.

## Reference Build Comparison
Compare the same product details page at https://practicesoftwaretesting.com before treating this as a confirmed bug.

## Reproducibility
Observed in the supplied screenshots. Confirm on a fresh page load and compare with the reference build.
