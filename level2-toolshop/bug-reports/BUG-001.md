# BUG-001: Add to Cart Button Remains Disabled

**Severity:** High 
**Priority:** High   
**Status:** Open  
**Module:** Shopping Cart  
**Application:** Toolshop – Bug-injected build  
**URL:** https://with-bugs.practicesoftwaretesting.com

## Preconditions
- The website is accessible.
- A product is available for selection.

## Steps to Reproduce
1. Open the bug-injected website.
2. Select a product and open its details page.
3. Locate the Add to Cart button.
4. Check whether it is disabled and attempt to add the product.

## Expected Result
The Add to Cart button should be enabled when the product is available.

## Actual Result
Earlier testing reported that the button was disabled. However, subsequent manual testing successfully added Combination Pliers to the cart. The original behaviour has not been consistently reproduced.

## Evidence
- Previously captured screenshot: `screenshots/cart-add-button-disabled.png` (recheck before relying on it).
- Re-run the automated test before treating this as a confirmed defect.

## Impact
If reproducible, users would be unable to add the affected product to their cart.

## Reference Build Comparison
Earlier notes indicated that the reference build passed and the bug-injected build failed. Repeat this comparison after reproducing the issue.

## Reproducibility
Not currently consistent. Do not report as a confirmed defect unless reproduced again.
