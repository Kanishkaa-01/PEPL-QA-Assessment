# BUG-006: Contact Navigation Label Is Misspelled

**Severity:** Low  
**Priority:** Low  
**Status:** Open  
**Module:** Navigation / User Interface  
**Application:** Toolshop – Bug-injected build

## Steps to Reproduce
1. Open the bug-injected website.
2. Inspect the main navigation bar.
3. Read the label for the Contact page.

The label should display "Contact".

## Actual Result
The navigation label displays "Contakt".
