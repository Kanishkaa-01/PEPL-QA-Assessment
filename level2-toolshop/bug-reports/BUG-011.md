# BUG-009: Incorrect Registration Form Fields and State Dropdown Options

**Bug ID:** BUG-011
**Title:** Registration form displays incorrect address fields and country names in the State dropdown  
**Severity:** High  
**Priority:** High  
**Status:** Open  
**Module:** Customer Registration  
**Environment:** Chromium Browser  
**Application:** Toolshop – Bug-injected build

## Preconditions
- The Toolshop website is accessible.
- The user is on the Customer Registration page.

## Steps to Reproduce
1. Open the bug-injected Toolshop website.
2. Navigate to Sign in.
3. Select Register your account.
4. Scroll to the address section of the registration form.
5. Observe the Country and State fields.
6. Open the State dropdown and inspect its options.

## Expected Result
The registration form should display the correct address fields, consistent with the reference application:
- Country should be a dropdown.
- Postal code, house number, street, city and state should have separate fields.
- State should be a text field rather than a dropdown containing country names.

## Actual Result
The registration form displays a different set of address fields. The Country field is a text input, while the State field is a dropdown containing country names such as Albania, Algeria and Australia instead of state names.

The form also uses a single Address field instead of separate house number and street fields.

## Evidence
**Screenshot:** `screenshots/BUG-009-registration-form.png`

## Impact
Users may enter incorrect or invalid address information during registration. The incorrect field labels and dropdown options can create confusion and affect the accuracy of customer address details.

## Reference Build Comparison
- Correct reference build: Displays separate address fields and the appropriate Country and State input types.
- Bug-injected build: Displays an incorrect address form, including country names in the State dropdown.

## Reproducibility
Reproduced manually by comparing the registration forms of both applications.
