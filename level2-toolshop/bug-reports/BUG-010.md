# BUG-010: Incorrect Category Names and Broken Category Navigation

**Bug ID:** BUG-010  
**Title:** Category menu displays incorrect categories and contains a broken navigation link  
**Severity:** High  
**Priority:** High  
**Status:** Open  
**Module:** Category Navigation  
**Environment:** Chromium Browser  
**Application:** Toolshop – Bug-injected build

## Preconditions
- The Toolshop website is accessible.
- The user can access the Categories dropdown.

## Steps to Reproduce
1. Open the bug-injected Toolshop website.
2. Click the Categories dropdown.
3. Observe the displayed category names.
4. Compare the categories with the reference website.
5. Click the Chainsaws category in the bug-injected build.

## Expected Result
The category menu should display the correct categories, matching the reference website:
- Hand Tools
- Power Tools
- Other
- Special Tools
- Rentals

Each category should navigate to its corresponding product listing page.

## Actual Result
- The menu displays **UNDEFINED** instead of **Other**.
- The **Special Tools** category is missing.
- An incorrect **Chainsaws** category is displayed.
- Clicking Chainsaws navigates to a 404 Page Not Found screen.

## Evidence
- Screenshot of the bug-injected category dropdown.
- Screenshot of the reference category dropdown.
- Screenshot of the 404 page after clicking Chainsaws.

## Impact
Customers may be confused by incorrect category names and may be unable to access products through category navigation. Broken category links negatively affect product discovery and usability.

## Reference Build Comparison
- Reference build: Displays the expected categories and valid category navigation.
- Bug-injected build: Displays an undefined category, has a missing category, and contains a broken category link.

## Reproducibility
Reproduced manually by comparing both websites and navigating to the Chainsaws category.
