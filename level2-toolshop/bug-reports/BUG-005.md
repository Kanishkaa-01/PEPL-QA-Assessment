# BUG-005: Home Navigation Opens the Contact Page

**Severity:** High  
**Priority:** High  
**Status:** Open  
**Module:** Navigation  
**Application:** Toolshop – Bug-injected build

## Steps to Reproduce
1. Open the bug-injected website.
2. Click the Home navigation link.
3. Observe the page content and URL.
4. Click Contact and compare its destination.

## Expected Result
Home should navigate to the product homepage. Contact should navigate to the Contact page.

## Actual Result
Both Home and Contact navigate to the Contact page. The observed URL for both is `#/contact`.

## Evidence
Screenshot showing the navigation and Contact page. Observed destination for both links: `#/contact`.

## Impact
Users cannot reach the homepage using the Home link.
